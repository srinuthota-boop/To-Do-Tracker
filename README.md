# To-Do List Project

A simple and professional To-Do List application built with HTML, CSS, and JavaScript. It helps users manage daily tasks, mark them as completed, delete them, and keep their list saved after refreshing the page using browser local storage.

## Project Overview

This project is a beginner-friendly task tracker designed to help users:
- add new tasks
- mark tasks as completed
- delete tasks individually
- keep tasks saved in the browser
- view the task list in a clean and responsive layout

## Features

- Add new task items
- Prevent empty task submission
- Mark tasks complete with a line-through effect
- Delete tasks individually
- Save tasks using Local Storage
- Automatically reload saved tasks after refresh
- Responsive interface for mobile, tablet, and desktop
- Simple and clean styling

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API

## How to Run

1. Open the project folder.
2. Locate the `index.html` file.
3. Open it in a browser.
4. Start adding tasks.

You can also use a local web server if you prefer, but this project works directly in the browser.

## Notes

This project is intentionally simple and beginner-friendly, making it a good learning example for HTML, CSS, and JavaScript fundamentals.
